# What do I do first?

To get started with this process, first you'll need to create a new campaign in this vault. Then you'll need to gather some info about that campaign and where its files are stored. 

## Create a Campaign in this Obsidian Vault First
Before you do any importing of data from the FMG JSON file, you need to create a campaign in this Obsidian vault. Use this button to do that now if you haven't already:

`BUTTON[new-campaign]`

> [!DANGER] - DO NOT IMPORT WITHOUT CREATING A CAMPAIGN FIRST

## Campaign Info Needed 
In the step above, when you created you campaign, you entered some info. You will need to know the following before proceeding:
 - Campaign Name 
	 - appears on the Campaign's Home Note - look in properties/metadata to get the exact name. Referred to by: `{thisCampaignName}` in these instructions.
 - Campaign Path 
	 - if you are creating this within the buttonpusherTTRPG vault, then all campaigns will be stored as sub-folders of the folder `01-Campaigns`. Referred to by `{thisCampaignPath}` in these instructions.
 - Campaign Short Code
	 - Again, you entered this when you created the campaign. It also can be found in the metadata/properties of the campaign's home note. Referred to by `{thisCampaignShortCode}` in these instructions.

> [!TIP] Suggested Vault Location to Store Campaign-related Assets
> When you created your new campaign, a folder called `98-{thisCampaign} Assets` was created.  Referred to by `{thisCampaignAssets}` in these instructions.
> 
> This is a good place to store any and all files that are generated by this import process. Not only will it serve to keep these related assets together, it also serves as a single place to store all the assets for this campaign.
> 
> Be sure to keep it organized by putting similar file types in subfolders and use descriptive names to help identify what the files are for and what kind of data they contain.
